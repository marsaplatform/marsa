# البدء

مرسى تحوّل مجلدًا من الملفات الثابتة إلى رابط عام ينتهي من تلقاء نفسه.
لا يوجد حساب: من يملك **مفتاح التعديل** يستطيع إدارة الموقع.

## هل أحتاج إلى تثبيت أي شيء؟

- **إذا كنت تستخدم نسخة مرسى** يشغّلها شخص آخر: لا شيء. ارفع من المتصفح أو استدعِ الـ API بـ `curl`.
- **إذا كنت تستضيف نسختك**: مرسى فقط، بأمر واحد: `docker compose up -d --build`. لا قاعدة بيانات ولا
  خدمات أخرى. كل ميزات النشر تعمل مباشرة.
- **خلفية البيانات والملفات الاختيارية** (KV وتخزين ملفات للصفحات والوكلاء) هي الشيء الوحيد الذي
  يستخدم خدمة خارجية: [Cloudflare Workers KV و R2](backend.md)، وهي معطّلة افتراضيًا. لا شيء
  لتثبيته؛ تربط حساب Cloudflare بمتغيرات البيئة.

## الرفع من المتصفح

1. افتح الصفحة الرئيسية وانزل إلى **جرّبها الآن** (أو اذهب إلى `/new`).
2. اسحب مجلدًا أو بعض الملفات أو ملف `.zip` واحدًا. يمكنك أيضًا استخدام **اختر ملفات** أو **اختر مجلدًا**.
3. اختر مدة بقاء الرابط (من ساعة واحدة حتى الحد الأقصى للنسخة، و٧ أيام افتراضيًا).
4. انسخ الرابط وأرسله لمن تريد.

يتذكر متصفحك المواقع التي رفعتها (مع مفاتيحها) تحت **مواقعك في هذا المتصفح**،
فتستطيع حذفها لاحقًا من المتصفح نفسه.

## ما الذي يجعل الموقع صالحًا

- ضع `index.html` في المستوى الأعلى. إذا كان كل شيء داخل مجلد واحد (مثل
  `my-site/index.html`) تزيل مرسى هذا المجلد تلقائيًا.
- استخدم روابط نسبية (`css/style.css` وليس `/css/style.css`)، لأن المواقع تعيش تحت `/s/<id>/`.
- ملف `404.html` في المستوى الأعلى يُستخدم للصفحات غير الموجودة.
- `about/` يعرض `about/index.html`، و`about` يجد أيضًا `about.html`.
- الملفات المخفية (`.env` و`.git/` و`.DS_Store`) تُحذف. سكربتات الخادم والملفات التنفيذية
  (`.php` و`.py` و`.sh` و`.exe` ...) تُرفض.

## ما الذي تحصل عليه

```json
{
  "id": "k3v9x2mq7a",
  "url": "https://marsa.example.com/s/k3v9x2mq7a/",
  "expiresAt": "2030-01-02T10:00:00.000Z",
  "editToken": "marsa_…",
  "fileCount": 3,
  "totalBytes": 18342
}
```

يُعرض `editToken` **مرة واحدة**. تحفظ مرسى بصمته (hash) فقط، فلا يمكن استرجاع مفتاح ضائع؛
وينتهي الموقع ببساطة في موعده.

## أشياء يجب معرفتها

- كل من لديه الرابط يستطيع فتح الموقع. لا ترفع أسرارًا أو بيانات شخصية أو أي شيء خاص.
- الصفحات المرفوعة تعمل داخل **عزل (sandbox)** في المتصفح: السكربتات تعمل، لكن الصفحة تحصل على أصل (origin) معزول.
  تخزين المتصفح (`localStorage` والكوكيز) غير متاح للصفحات المرفوعة.
- الصفحات معلّمة بـ `noindex`، فيُطلب من محركات البحث ألا تفهرسها.

التالي: [استخدم الـ API](api.md) أو [دع وكيل ذكاء اصطناعي ينشر لك](agents.md).
