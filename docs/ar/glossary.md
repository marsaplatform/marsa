# المصطلحات

قائمة المصطلحات التي تستخدمها مرسى Spaces في الواجهة والتوثيق العربي، حتى تبقى الكلمة نفسها في كل مكان. الأسماء التقنية (API و MCP و KV و R2 و Cloudflare) تبقى بالإنجليزية.

| بالإنجليزية | بالعربية | ملاحظات |
|---|---|---|
| Space / Site | مساحة / موقع | «المساحة» صفحة أو موقع منشور برابط. |
| Team | فريق | |
| Team key | مفتاح الفريق | يملك كل الصلاحيات. |
| Agent | وكيل (الجمع: وكلاء) | لا نستخدم «إيجنت» أو «إيجنتس». |
| Agent key | مفتاح الوكيل | مفتاح بصلاحيات محددة ومدة انتهاء. |
| Edit token | مفتاح التعديل | لموقع واحد. |
| Worker | وركر (الجمع: وركرات) | Cloudflare Worker. |
| MCP server | خادم MCP (الجمع: خوادم MCP) | لا نستخدم «سيرفر». |
| Plain var | متغير عادي | |
| Secret | سر (الجمع: أسرار) | للكتابة فقط، لا يُعرض أبدًا. |
| Binding | ربط | |
| requiredEnv | requiredEnv | الأسماء المعلنة التي يحتاجها الوركر. |
| Health check | فحص الصحة | «يعمل» / «متوقف». |
| Uptime | مدة التشغيل | |
| Logs | السجلات | |
| Usage | الاستخدام | |
| Activity | النشاط | سجل من فعل ماذا ومتى. |
| Notes | الملاحظات | ملاحظات الوكلاء للإدارة. |
| Recipe | وصفة | |
| Admin | الإدارة / المسؤول | «الإدارة» للمكان، «المسؤول» للشخص. |
| Backup | نسخة احتياطية | |
| Trash | سلة المحذوفات | تُحذف نهائيًا بعد ٧ أيام. |
| Export | تصدير | |
| Webhook | Webhook | |
| Permanent | دائم | رابط لا ينتهي. |
| Expiry | الانتهاء | |

## قواعد

- الأرقام في الواجهة العربية بالأرقام العربية (٠١٢٣…)، إلا داخل الكود والمعرّفات.
- عناوين الصفحات: «الصفحة · اسم الفريق · مرسى Spaces» للفريق، و«الصفحة · الإدارة · مرسى Spaces» للإدارة.
- الأسماء التي يكتبها المستخدم (اسم الوركر، اسم المفتاح) لا تُترجم.
